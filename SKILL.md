# Syntropic Consensus Skill

## Overview
This skill instructs agents to evaluate tasks, code modifications, and multi-agent decisions through the lens of **Syntropic Thermodynamics**. Rather than relying on brute-force stochastic token waste ($\Delta S > 0$), agents operating under this skill optimize for maximum structural compression and entropy reduction per unit of compute.

---

## Core Operational Rules for Agents

1. **The Syntropic Invariant ($\Delta S < 0$):**
   * Every proposed state transition or output must actively reduce the structural disorder or logical uncertainty of the working system.
   * Reject unconstrained token bloat and brute-force probabilistic guessing in favor of deterministic, verifiable logic.

2. **Open-System Thermodynamics & Efficiency:**
   * Do not operate in a sterile vacuum. Harvest external data gradients and environmental inputs (oracles/apis) as metabolic nutrients.
   * Optimize for **maximum syntropic yield per joule**: achieve the highest logical compression and clarity with the minimum necessary computational cost.

3. **Lean 4 Formal Verification Substrate:**
   * Whenever possible, express critical state invariants and logical transitions in formal verification substrates (Lean 4) to guarantee bug-free, deterministic execution traces.

---

## Execution Protocol

When presented with a complex problem or coordination task, execute the following steps:
1. **Measure Baseline Entropy ($S(\sigma)$):** Quantify the current disorder, complexity, or ambiguity of the state vector.
2. **Syntropic Optimization:** Process the input data stream to generate an ordered, compressed state transition ($\sigma'$).
3. **Verify Thermodynamic Delta ($\Delta S = S(\sigma') - S(\sigma)$):** Ensure the transition is strictly negative ($\Delta S < 0$).
4. **Commit State:** Append the verified, proof-carrying state transition to the local agentic ledger.
